# 🛒 Walmart Sales SQL Analysis

## 📌 Project Overview

This project is an end-to-end SQL data analysis of the Walmart Sales dataset using MySQL. The objective is to transform raw sales data into meaningful business insights through data cleaning, feature engineering, exploratory data analysis (EDA), and SQL-based reporting.

The project demonstrates SQL skills commonly used by Data Analysts, including aggregations, joins, subqueries, CTEs, window functions, and business KPI analysis.

---

## 📊 Dataset Information

The dataset contains **1,000 sales transactions** with **17 attributes**, including:

* Invoice ID
* Branch
* City
* Customer Type
* Gender
* Product Line
* Unit Price
* Quantity
* Tax (VAT)
* Total Sales
* Date & Time
* Payment Method
* Cost of Goods Sold (COGS)
* Gross Income
* Customer Rating
